# SauceDemo Manual Testing Project

## Project Overview

This project contains manual functional testing performed on the **Swag Labs (SauceDemo) web application**.

The purpose of this project was to practice the complete manual testing process, including test case creation, test execution, defect reporting, and test summary preparation.

## Application Tested

**Application:** Swag Labs (SauceDemo)

**Testing Type:** Manual Functional Testing

## Testing Activities

* Created 27 test cases
* Executed the test cases
* Tested valid and invalid user interactions
* Verified application functionality
* Identified and documented defects
* Created a bug report
* Prepared a test summary report
* Added evidence for the identified defect
